# 手动验收清单

## 日程管理

- 可以新建带标题、开始时间、结束时间的日程
- 空标题保存会失败
- 可以编辑已有日程
- 可以删除已有日程
- 全天、完成状态、优先级、地点、标签可以保存并重新加载

## 日历视图

- 日视图显示当天日程
- 周视图显示一周日程
- 月视图显示整月日程
- 年视图显示全年日期布局
- 日期格显示农历日期，节气日期优先显示节气
- 2026 年法定节假日显示“休”，调休上班日显示“班”
- 点击日期会带入对应日期创建新日程
- 点击日历事件会打开编辑面板

## Markdown

- Markdown 正文可以保存
- checklist 可以预览
- 表格可以预览
- 链接可以预览
- 代码块可以预览

## 提醒

- 设置当前时间之前或附近的提醒
- 应用运行时最多 30 秒内触发系统通知
- 已通知日程不会重复提醒
- 完成状态的日程不会提醒

## 导入导出

- 点击导出 JSON 后显示导出路径
- 导出的 JSON 包含当前全部日程
- 点击导入后可以选择 JSON 文件
- 导入完成后日历重新加载
