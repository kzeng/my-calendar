# 我的日历 PRD

## 目标

构建一个个人使用、个人维护的本地桌面日历，重点解决“清晰查看日、周、月、年安排”的问题，同时支持快速记录 Markdown 日程和运行时提醒。

## 用户

- 主要用户：开发者本人
- 使用设备：Ubuntu/Linux 优先，Windows 第二优先级，macOS 兼容但不作为第一版发布目标
- 使用方式：本地桌面应用，无账号、无多人协作

## 第一版功能

### 日程管理

- 创建、编辑、删除日程
- 字段包含：
  - 标题
  - 开始时间
  - 结束时间
  - 全天事件
  - Markdown 正文
  - 标签
  - 地点
  - 优先级
  - 提醒时间
  - 完成状态

### 日历视图

- 日视图
- 周视图
- 月视图
- 年视图
- 年视图只显示日期密度和跳转能力，不展开每天的事件标题
- 月视图和年视图的日期格显示农历日期，遇到节气优先显示节气
- 日期格显示中国法定节假日和调休上班日，当前内置 2026 年国务院办公厅放假安排

### Markdown

- 支持 Markdown 文本编辑
- 支持预览
- 支持 GFM checklist、代码块、表格、链接
- 第一版不做所见即所得编辑

### 提醒

- 第一版只在应用运行时检查提醒
- 到期后触发桌面系统通知
- 通知触发后标记为已通知，避免重复弹出
- 不做后台常驻和开机自启动

### 导入导出

- 第一版支持 JSON 导入和导出
- JSON 格式按当前事件模型输出，后续可作为导入兼容基础

## 明确不做

- 账号系统
- 多人协作
- 云同步
- 重复规则
- ICS 导入导出
- 应用关闭后的提醒
- 后台常驻
- 开机自启动
- 移动端应用

## 成功标准

- 用户可以在桌面应用中完成日程创建、编辑、删除
- 用户可以在日/周/月/年视图之间切换并查看同一批本地日程
- 用户可以输入 Markdown 并看到预览
- 用户可以设置提醒，并在应用运行期间收到系统通知
- 用户可以导出 JSON 备份
